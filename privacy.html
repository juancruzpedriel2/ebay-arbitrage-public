Privacy Policy

Last updated: September 27, 2026

This privacy policy describes the data handling practices of the private internal application "Internal eBay Product Research and Purchasing Decision Support."

Purpose

The application is used privately by its operator to research products listed on eBay US, evaluate potential manual purchases, and maintain product and listing observations for internal decision support.

Data processed

The application may process information made available through eBay APIs, including listing details, item identifiers, seller information, pricing, availability, shipping-related information, and other data required for product research and evaluation.

Authentication and credentials

The application uses eBay API application credentials for authorized API access. It does not request or collect eBay account passwords from users.

Use and sharing

Data obtained through eBay APIs is used only for the private internal purposes described above. The application is not offered as a public service and does not sell or intentionally share eBay API data with third parties.

Data retention and deletion

Data is retained only as needed for the application's internal research, operational, historical, and legitimate recordkeeping purposes. eBay account deletion notifications are processed through the application's configured marketplace account deletion endpoint, and applicable eBay user data is deleted or anonymized in accordance with the application's compliance process.

Security

API credentials and other sensitive configuration values are stored separately from publicly accessible application content. Reasonable technical measures are used to restrict access to the application's data and credentials.

Changes

This policy may be updated as the application or applicable requirements change. The latest version will be made available at this URL.
